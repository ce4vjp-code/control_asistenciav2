Manual de Usuario - Sistema de Asistencia

1. Introducción

Bienvenido al Manual de Usuario del Sistema de Asistencia del Liceo TP Gonzalo Guglielmi Montiel. Este sistema ha sido diseñado para registrar de manera eficiente la asistencia de los estudiantes y el acceso al comedor, así como gestionar datos y reportes.

2. Inicio de Sesión (Login)

Para acceder al sistema:

  1. Abra la aplicación "Asistencia Liceo TPGGM".
  2. Ingrese su Usuario y Contraseña provistos por el establecimiento.
  3. Haga clic en Iniciar Sesión.

3. Escáner Colegio (Entrada y Salida)

Este módulo es utilizado para registrar la hora de llegada y salida de los alumnos.

  1. Seleccione el botón Escáner Colegio en el menú lateral.
  2. Posicione el cursor en el campo de lectura.
  3. Utilice el lector de códigos de barras para escanear la credencial del estudiante, o digite manualmente su RUT y presione Enter.
  4. El sistema registrará automáticamente el ingreso o la salida según corresponda.

4. Escáner Comedor

Módulo para registrar a los estudiantes que ingresan al servicio de alimentación.

  1. En el menú principal, seleccione Escáner Comedor.
  2. Escanee la credencial del alumno o digite su RUT.
  3. El sistema confirmará el ingreso del estudiante al comedor para el día en curso.

5. Gestión de Alumnos y Usuarios

Opciones exclusivas para personal con permisos de administración.

5.1 Gestión Alumnos

  1. Seleccione Gestión Alumnos en el menú lateral.
  2. Aquí puede buscar estudiantes, así como editar o eliminar registros existentes usando los botones correspondientes en la interfaz.

5.2 Usuarios

  1. Seleccione el botón Usuarios en el menú.
  2. Permite visualizar a los operadores y administradores del sistema.
  3. Puede crear, modificar roles y actualizar credenciales de los distintos usuarios.

6. Reportes y Registros

Módulo para la consulta y exportación de la asistencia diaria y el comedor escolar.

  1. Haga clic en Reportes y Registros.
  2. Utilice los selectores de Fecha y Curso para filtrar la información deseada.
  3. Utilice el botón INASISTENCIAS para visualizar alumnos que no asistieron.
  4. Utilice el botón COMEDOR PENDIENTE para revisar registros pendientes relacionados al comedor.
  5. Use el botón GUARDAR PDF para exportar el reporte generado a un documento PDF.
  6. Use el botón ENVIAR A ADMINS para enviar el reporte por correo a la dirección.

7. Sincronización de Datos y Notificaciones

  1. Actualizar información: Si su equipo está conectado a internet, haga clic en el botón Actualizar información. El sistema procesará el envío y recepción de registros de manera automática y le confirmará con un mensaje de "Éxito".
  2. Descargar Reportes: El botón Descargar Reportes (ícono de campana) le notificará si el sistema generó reportes automatizados (por ejemplo, reporte automático de comedor). Haga clic en él para descargar el archivo PDF.
